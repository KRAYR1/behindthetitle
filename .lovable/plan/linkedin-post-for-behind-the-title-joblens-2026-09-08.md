# LinkedIn Post for Behind The Title / JobLens

## Goal
Create a LinkedIn post that tells my network about this project and frames it as the capstone project for my Flyrank AI internship as a Frontend AI Developer Intern.

## What the post should cover
- Hook: the problem job seekers face with generic AI resume tools.
- Project intro: "Behind The Title" (formerly JobLens) — paste a job description and resume bullets to get a keyword match score, honestly rewritten bullets, and visible skill gaps.
- Capstone context: built as the capstone project for my Frontend AI Developer Internship at Flyrank AI.
- Meaningful AI integration: structured `generateObject` output via the Vercel AI SDK, Google Gemini / Lovable AI Gateway, with a deterministic offline fallback so the app never fabricates experience.
- Frontend craft: TanStack Start, React 19, Tailwind CSS v4, accessible UI (progress bar, radio group, alerts, copy buttons), semantic HTML, AA contrast.
- Quality bar: 29 tests, ~97% statement coverage, Lighthouse 100 for accessibility/SEO/best-practices, axe-core 0 violations.
- Personal reflection / call to action: invite feedback, share the live link, mention what I learned about AI reliability, error handling, and deployment.

## Deliverables
1. A ready-to-copy LinkedIn post (plain text, ~150–200 words, with hashtags).
2. Optionally save it to `docs/linkedin-post.md` for version control.
